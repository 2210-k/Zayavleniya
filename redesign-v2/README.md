# Zayavleniya — Redesign V2

Цель ветки: единый рабочий интерфейс документооборота без смешивания старых страниц и стилей.

Правила V2:
- единая тёмная тема для административного интерфейса;
- действия находятся непосредственно в очереди дел;
- карточка дела является рабочим местом администратора;
- формы могут быть привязаны к конкретному заявлению;
- оспаривания имеют отдельные решения и историю;
- существующие Supabase-данные не удаляются.

Перед публикацией проверить все HTML из корня и отсутствие старых inline style-блоков, которые переопределяют общую тему.
