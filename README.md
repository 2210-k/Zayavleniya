# Zayavleniya

Система электронных заявлений для игровой юрисдикции.

## Правила дат
- Реальная дата ставится системой автоматически.
- Игровая дата вводится только там, где она является частью официального события/документа.
- Для сообщений игровая дата **не запрашивается** и не вводится пользователем.

## Интерфейсы
- Гражданин: обзор, заявления, формы от ведомства, сообщения, профиль.
- Администратор: обзор, заявления, оспаривания, граждане, формы, сообщения, обслуживание.

Сообщения гражданина и ведомства визуально различаются, а переписка по заявлению находится непосредственно в карточке заявления.
